# Security Policy

## Supported versions

SlideDSL is an early-stage project (pre-1.0). Security fixes are applied to the
latest version on the `main` branch. Older tagged releases are not maintained.

| Version | Supported |
|---------|-----------|
| `main` (latest) | ✅ |
| Older releases  | ❌ |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report them privately using either of these channels:

1. **GitHub private vulnerability reporting** (preferred): go to the repository's
   **Security** tab → **Report a vulnerability**. This opens a private advisory visible
   only to the maintainer.
2. **Email:** menilub@gmail.com

Please include, where possible:

- A description of the vulnerability and its potential impact.
- Steps to reproduce (a minimal `.sdl` input or command is ideal).
- Any suggested remediation.

## What to expect

- **Acknowledgement:** I aim to acknowledge your report within a few days.
- **Disclosure:** Please give me a reasonable opportunity to investigate and release a
  fix before any public disclosure. I'll keep you updated on progress and credit you in
  the fix unless you prefer to remain anonymous.

Thank you for helping keep SlideDSL and its users safe.
